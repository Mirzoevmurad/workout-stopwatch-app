# Секундомер для тренировок

Приложение секундомера на основе Streamlit, предназначенное для отслеживания тренировочных сессий. Приложение предоставляет основные функции тайминга, необходимые для тренировок и спортивных занятий.

## Особенности

- **Старт/Пауза/Продолжить**: Управление секундомером с помощью интуитивных кнопок
- **Сброс**: Очистить все времена и начать заново
- **Времена кругов**: Запись промежуточных времен во время работы секундомера
- **Форматированный дисплей**: Показывает время в формате ЧЧ:ММ:СС.мс
- **История кругов**: Просмотр всех записанных времен кругов с суммарными итогами
- **Обновление в реальном времени**: Время обновляется непрерывно во время работы

## Требования

- Python 3.7+
- Streamlit

## Установка

1. Клонируйте или скачайте этот репозиторий
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   streamlit run streamlit_app.py
   ```

## Использование

1. Нажмите **Старт**, чтобы начать отсчет времени вашей тренировки
2. Нажмите **Пауза**, чтобы временно остановить тайминг
3. Нажмите **Круг**, чтобы записать промежуточное время во время работы
4. Нажмите **Сброс**, чтобы очистить все времена и начать сначала

## Интерфейс

- **Зеленая кнопка Старт**: Запускает секундомер
- **Желтая кнопка Пауза**: Приостанавливает таймер
- **Красная кнопка Сброс**: Очищает все времена
- **Синяя кнопка Круг**: Записывает времена кругов во время работы
- **Дисплей времени**: Показывает текущее прошедшее время в формате ЧЧ:ММ:СС.мс
- **Раздел времен кругов**: Отображает записанные времена кругов с общим прошедшим временем

## О приложении

Это приложение специально разработано для любителей тренировок, которым нужен простой и надежный секундомер для отслеживания их тренировочных сессий. Чистый интерфейс обеспечивает легкую эксплуатацию во время интенсивных тренировок.
